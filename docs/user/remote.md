# The remote

The same guide is in the app under **Settings → Help → Remote buttons**.

## While listening

| Button | Does |
| --- | --- |
| Red | Chapters, bookmarks and the playlist |
| Green | Playback speed |
| Yellow | Sleep timer |
| Blue | Bookmark this moment (books) |
| Channel + / − | Next or previous chapter |
| Left / Right on the progress bar | Move through the book, OK to jump, Back to cancel |

## Anywhere

| Button | Does |
| --- | --- |
| OK | Choose |
| Back | Go back. From the player, back to browsing. From Home, back to the player |
| Play, Pause, Stop | Play or pause what's loaded |
| Rewind, Fast-forward | Skip back or forward by the lengths in Settings |
| Blue | Back to the player |

## The Magic Remote

Pointing at anything focuses it, and OK or a click chooses it. The wheel moves up and down between rows and lists. While you're using the pointer, arrows appear at the ends of each row of covers to move it along.

## On particular screens

| Where | Button | Does |
| --- | --- | --- |
| Home, In progress | Red | Remove from Continue listening. Red again soon after undoes it |
| A podcast's episodes | Red | Mark played or unplayed |
| Library filter | Red | Show all books again |
| Library filter, long lists | Left / Right | Jump to the previous or next letter |
| Library, by narrator | Channel + / − | Next or previous letter |
| A playlist | Green | The focused entry's details (or the show, for an episode) |
| Chapters, playlists, filter lists | Channel + / − | Jump eight at a time |
| Settings, Home rows | Channel + / − | Move a row up or down |
| Settings, rows with a range | Left / Right | Step the value down or up |
